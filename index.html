Retrieval experiment

Numbers come from the last saved run. They measure Fashion-MNIST class match, not shopper satisfaction. Recall@10 cannot exceed 0.10 because each class has 100 index images.

Synthetic evaluation

Runs the hand-labelled shopper scenarios against the v1 baseline and the hybrid ranking. The labels were written from attributes, not from the ranker. Precision, NDCG, coverage, diversity, and runtime are reported as measured, including where the hybrid ranking scores lower. This is not a user study.

The shopper form ranks 60 fictional products with the attribute engine. Image and text search uses a separate Fashion-MNIST index and CLIP. Class match on that index is not a real-world fashion recommendation. Similarity in the shopper results still means related attributes, not a duplicate listing.
