Guided fashion discovery

FitRank

Tell FitRank what you are shopping for today, how you want the piece to fit your wardrobe, and what you can spend. It ranks a local catalogue and explains which trade-offs the shortlist actually supports.

Brands, prices, and ratings here are fictional. This is not a shop, and nothing in the catalogue is real retail inventory.

Shopping questions

Seven short questions, then the practical limits. This is about the purchase you are making now.

Recommendations

More like this and Less like this change this search only. FitRank does not learn from past shoppers, and it does not know what is already in your wardrobe.

Comparison

Value uses the synthetic review estimate and room under your budget. It is not a fair-price judgement.

Image and text search

This searches a separate Fashion-MNIST index with CLIP. It does not replace the shopper form, and class match on these 28×28 images is not a real-world fashion recommendation. Budget, size, and stock are absent, so asking for them stops the search instead of inventing a value.

Result order

Retrieval experiment

Numbers come from the last saved run. They measure Fashion-MNIST class match, not shopper satisfaction. Recall@10 cannot exceed 0.10 because each class has 100 index images.

Synthetic evaluation

Runs the hand-labelled shopper scenarios against the v1 baseline and the hybrid ranking. The labels were written from attributes, not from the ranker. Precision, NDCG, coverage, diversity, and runtime are reported as measured, including where the hybrid ranking scores lower. This is not a user study.

The shopping questions rank 60 fictional products. Category and aesthetic tags added for this questionnaire are synthetic labels. Image and text search uses a separate Fashion-MNIST index and CLIP. Class match on that index is not a real-world fashion recommendation. Similarity in the shopper results still means related attributes, not a duplicate listing.
